## 先确认 endpoint

核实官方同步接口文档、价格、批量与长度限制、支持维度、query/document 编码参数及地域/业务空间地址：https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api 。主会话本日查到 v4 每批最多 10 条、单条 8192 tokens，默认 1024 维；实现时仍以所用接口的官方契约为准。

选择原生或兼容接口中的一种并说明理由，不混用其请求/响应格式。从现有非敏感配置或用户控制台信息确认实际地址；缺少地域/业务空间信息时先完成离线实现，向用户索取 endpoint 或地域信息。不得发送密钥去探测不同供应商、地域或猜测地址。

## 配置与客户端

- 独立读取 embedding 配置，校验 provider、model、api_key 及必要 endpoint/维度配置。支持现有 --config/default 路径约定；缺字段、错误类型、空值和示例占位符在联网前失败。保留原 DeepSeek 读取行为。
- config.example.toml 只保留明确占位符和非敏感说明。实际配置如需增补，由用户填写或在其明确提供信息后最小更新，不覆盖现有密钥。
- 复用适当 HTTP 能力或成熟 SDK，说明依赖取舍；不强制零依赖，也不为单一供应商建立通用适配平台。新增依赖通过 uv 管理并锁定。
- 提供简单的本地验证入口。明确 30 秒请求超时，无自动重试；SDK 默认重试也需关闭。实际请求尝试和失败前已知用量要能记录。
- 文档与问题编码统一模型/维度；按所选官方接口使用合适的文本类型或编码设置，不照搬 BGE 检索前缀。保存非敏感编码配置以便后续复现。
- 校验响应个数、索引完整唯一及输入顺序映射；每个向量长度一致且符合预期，元素是有限数值而非 bool，不接受零范数。报告范数，不假设服务天然归一化，不自行改变向量却不记录。
- 有效 usage 在其他响应校验失败时也尽量保留；无有效用量标未知，不当成零计费。记录供应商请求 ID（如有）和安全错误，不保存密钥、请求头或原始错误正文。

## E1 输入与验证结果

读取 E1 正常 prepared corpus，不使用 corrupt-copy。编码前运行 E1 check，过期或损坏时停止且零 API 调用；不自动重建。保留 chunk_id 与输入行的对应关系，不修改 E1 来源或指纹。

验证结果写入已忽略的 test-output/，拒绝覆盖已有文件，在请求前预留输出位置。可保存向量及来源 ID、模型/维度/编码方式、E1 build_id、批次/映射、有效用量和错误。这是编码验证结果，不是已完成的正式检索索引。

不静默截断文本。不为准确算 tokens 引入本地推理模型；根据官方接口限制设计长度保护，限长错误安全返回，记录尚未具备精确本地 token 预检的限制。

## 离线验证与真实调用预算

先做假密钥/预设响应的离线测试，再完整回归。验证配置失败不联网、批次/顺序映射、缺失/重复索引、非法向量、维度错误、HTTP/超时安全记录、usage 未知、E1 过期/损坏阻止调用、输出不覆盖。

离线通过、endpoint 确认后，授权一次受控验证：15 个现有片段按官方批量上限分批编码，再编码一个问题“数据库迁移失败后，重跑前需要检查什么？”。最多 3 次 HTTP 请求尝试（包含失败），无自动重试；不另发独立健康检查，不调用 DeepSeek 生成，不反复重新采集。若当前片段数量变化导致超过预算，仅编码小样本并说明范围，不扩大预算。

任何请求失败即停止后续验证，保留已知用量与部分结果，不通过切换地域/模型继续尝试。没有网络权限或必要地址时报告受阻，不绕过权限。真实密钥只在程序认证时读取，不显示在工具输出、命令参数、聊天或保存结果中。

记录实际请求数、向量数量/维度、对应 ID、已知 tokens、缺失用量及耗时；依据实际用量与已核实地域费率估算费用，明确不是账单。不能因为结构合法就宣称检索或语义质量通过。40 分钟为范围参考，额外功能不顺手实现。
