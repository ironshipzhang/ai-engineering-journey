# 下一项任务：结构化运行结果与执行轨迹

阅读 AGENTS.md、README.md、docs/PROGRESS.md、docs/ARCHITECTURE.md、docs/TOY_AGENT_ROADMAP.md，以及 toy-agent/src/deepseek_summary.py 和相关测试。

## 本轮目标

把当前只能在终端阅读的 Loop，改成可由程序检查的运行结果与事件轨迹。先说明最小设计再编码，不要实现后续路线。

主会话已决定结束当前内容调优阶段：冻结 SUMMARY_PROMPT，保留候选的已知字段限制，不再追求八条样例全部通过，不重新进行内容采集。

## 最小设计

采用标准库 dict 或 dataclass，选一种易懂的结构即可。运行结束返回：
- status：succeeded / failed，表示执行及结构校验结果，不表示事实质量已通过。
- summary：成功时为已校验摘要，失败时为 null。
- error：失败类别和本地安全说明；成功时为 null。
- model_requests：实际尝试请求数，包含网络失败的那次。
- usage：累计已知输入、输出和总 Token；另标明用量是否完整，未知不得当作零计费。
- tool_executions、cache_hits：工具函数实际调用次数（含进入函数后失败的调用）和缓存复用次数；非法调用未执行不计入 tool_executions，轨迹区分成功与失败。
- trace：按执行顺序记录请求与工具事件。只保存必要元数据。

轨迹应能说明每轮请求序号、结束原因、已知用量，以及工具名、当前调用 ID、经过校验的参数、实际执行或缓存命中、失败阶段。
网络无有效响应仍有失败事件。非法调用不得表现为已执行；第五轮要求工具时记录超限，不执行工具。无有效用量的请求，其该轮用量填 null，累计标明只是已知值；未发请求时已知累计可为零。

不记录密钥、Authorization、完整请求头、原始错误响应或完整对话。不保存模型内部推理。当前虚构参数可记录，说明以后接真实数据需要脱敏。

将运行逻辑与终端展示适度分离，CLI 继续展示摘要/用量和安全错误，成功退出码 0、失败 1。可选 --output 保存结果 JSON，拒绝覆盖已有文件；在付费请求前检查/预留输出位置，输出失败返回非零。默认命令继续可用。摘要评估脚本的公共函数行为保持兼容。

## 保持现有机制

最多 5 次模型请求，每轮最多一个工具调用；只有成功获得项目数据才能提交摘要；成功结果仅任务内复用，仍绑定当前 ID；非法调用、未知项目、截断和超限停止。
保持现有传输限制、无自动重试、无新依赖。不要实现 Tool Registry、多项目、RAG、MCP、重试或自动语义评分。

错误返回方式可为本轮进行最小调整，但必须保留现有准入与停止语义，不静默吞错或把失败当成功。

## 验证

本轮只做离线验证，不读取真实密钥、不调用模型。
运行原有测试；若测试原先依赖函数抛异常，可按新返回契约调整，但保留“不执行非法工具、不继续请求”等核心断言。
针对有意义的运行行为验证：正常成功、重复调用缓存、第二轮超时、非法参数、工具失败、第五轮停止、无数据直接回答、结果文件拒绝覆盖。
检查请求计数、已知用量与完整性标记、当前 ID、失败前轨迹保留，避免测试只镜像数据结构。
