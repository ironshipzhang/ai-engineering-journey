# 小型项目摘要事实评估

## 范围与数据

本轮只测“给定项目状态 → 结构化摘要”，不重复评估工具选择或 Loop 控制。使用已有 SUMMARY_PROMPT、deepseek-flash、非思考模式、JSON 输出、400 输出 tokens 与 30 秒网络操作超时，每条样例一次请求，无自动重试、无额外评判模型或依赖。

评估集：[project_summary_cases.json](../toy-agent/evals/project_summary_cases.json)，6 条虚构状态，覆盖未解除阻塞、多个阻塞、明确无阻塞、信息不足、阻塞已解除和条件计划。每条样例包含 status、按摘要字段列出的 required_facts，以及 unsupported_claims。后两项仅用于本地评审，不发送给生成模型。

真实基线：[baseline_20261010.json](../toy-agent/evals/baseline_20261010.json)，保存当时的提示词、模型、原始样例、有效摘要、结束原因和用量。不含密钥；factual_review=pending 表示采集脚本没有自动给事实结论，本页另记录 Codex 逐条对照的初评，待用户复核。

## 评审标准

1. 格式：必须通过已有 parse_summary；截断、异常结束、工具调用或非法结构视为生成失败，不能算事实通过。
2. 阻塞遗漏：每个仍有效的阻塞与明确风险都应出现在 blockers；已解除的阻塞不得当作当前阻塞。
3. 事实保留与字段：required_facts 是语义检查点，不要求逐字匹配；关键事实需出现在对应字段。把下一步计划只写进 blockers 记为字段归属问题；完全不提条件计划记为遗漏。
4. 无依据的信息：摘要每项须可由原文支持，不得增加负责人、时间、完成状态或确定性承诺；尤其不能把“计划、如果、可能”升级为事实。
5. 信息不足：依现有提示词，无对应信息可用 []；这只能表示未提取出阻塞，不能证明项目无阻塞。explicit_no_blockers 与 missing_information 都可能输出 []，当前摘要结构无法区分这两种知识状态。

不使用关键词命中率或唯一参考答案作为事实正确率：同义表达可能正确，带否定或已解决状态的关键词命中也可能错误。每次结果应逐条对照，而不是因为 JSON 合法就宣称事实正确。

## 首轮基线：2026-10-10

6 次请求全部 stop，结构通过 6/6。累计输入 1148、输出 244、总计 1392 tokens；按此前查验的未命中峰值费率估算上限约 $0.0006372，实际费用以账单为准。

以下为 Codex 对照原文与样例规则的初评，非评估脚本自动评分，也尚未经用户确认：

| 样例 | 当前阻塞/风险保留 | 无依据的信息 | 其他事实与字段检查 |
|---|---|---|---|
| active_blocker | 通过：迁移失败与演示延期风险都保留 | 未发现 | 未通过：周五演示计划仅在 blockers，next_steps 未保留该计划 |
| multiple_blockers | 通过：权限与支付回调两个阻塞都保留 | 未发现 | 通过：两个对应行动保留，未补上线日期或负责人 |
| explicit_no_blockers | 通过：未新增阻塞 | 未发现 | 通过：完成状态与文档行动保留 |
| missing_information | 通过：没有凭空添加阻塞 | 未发现 | 通过：原型完成和评审计划保留，未明确断言无风险；[] 仍有上述表达限制 |
| resolved_blocker | 通过：已修复迁移未作为当前阻塞 | 未发现 | 通过：验证通过及联调仍在进行被保留 |
| conditional_plan | 通过：安全评审阻塞保留 | 未发现 | 未通过：省略了评审通过后计划下周二发布，只有提交材料 |

结论：本轮关键阻塞/风险保留初评 6/6，未发现编造 6/6；按全部 required_facts 与字段归属要求，初评通过 4/6。小样本、单次生成和复核主观性意味着这些比例不能代表模型整体可靠性。当前只建立基线，不自动改提示词或摘要结构来追分。

## 运行与复核

在仓库根目录运行（会产生模型费用；输出父目录需存在，文件必须不存在）：

```sh
toy-agent/.venv/bin/python toy-agent/evaluate_summary.py --key-file /Users/ironshipzhang/Documents/secret/deepseek.txt --output /private/tmp/project-summary-eval-new.json
```

每个样例独立，单条失败后记录安全错误并继续下一个样例，不重试失败请求。有效响应中的用量即使摘要校验失败也计入累计；无有效响应时 usage=null，累计只是已知用量。存在生成失败时退出码 1，全部格式成功时退出码 0；退出码 0 不代表事实质量通过。脚本拒绝覆盖已有输出文件。

离线测试沿用现有命令，不读密钥、不调用模型：

```sh
toy-agent/.venv/bin/python -m unittest discover -s toy-agent -p 'test_*.py' -v
```

本次 30 项离线测试通过，覆盖样例校验、规则不进入模型输入、结果采集、格式失败保留用量、网络失败不重试和禁用工具时保留请求限制；原有 Loop 测试仍通过。它们验证程序机制，不证明模型事实质量。

尚未验证：多次采样稳定性、完整 Loop 在这 6 条状态下的端到端质量、真实异常响应，以及自动语义评分。下一步待主会话讨论本轮两个问题，决定是否调整提示词或评估标准；不自动实现。
